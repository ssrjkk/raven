Tools

Every tool, and a console to call it

The registry below is generated from tools/list on a live raven-mcp process: name, description, parameter names and types from each tool's JSON Schema. Select a row to build its tools/call frame, then send it in the console. The address bar keeps the state, so #tool=read and #cat=file are links to a tool and a category.

    Protocol

    Send a request

    Build a real JSON-RPC 2.0 frame in your browser: start from an example, edit it, or select a tool in the registry and the frame comes pre-filled.

    raven-mcp — request builder 66 tools reachable

    Enter sends the frame, Shift+Enter adds a line, and the Up and Down arrow keys recall earlier frames. The eight exchanges behind these buttons were captured from a live raven-mcp process, including its -32602 and -32601 replies. Anything outside that recording is answered by a running server, not by this page.
