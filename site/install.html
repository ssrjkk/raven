Setup

Install and configure

Three steps from a clone to a client calling tools.

1

Install the server

shell 
git clone https://github.com/ssrjkk/raven
cd raven
pip install .

Python 3.11+ · installs the raven-mcp and ravencode-mcp commands

2

Add it to your client

json 
{
  "mcpServers": {
    "raven": {
      "command": "raven-mcp",
      "args": ["--workspace", "/path/to/project"]
    }
  }
}

Same shape for every MCP client that starts a stdio server

3

Call the tools

Ask the assistant to read a file, run a command or search the web. It calls the MCP tool and Raven runs it inside the workspace you allowed. Over HTTP, the same tools answer POST /mcp/rpc with a bearer key.

Run the gateway

The same install also starts the gateway — the process that holds the channel adapters, the DM policy and the web console.

shell 
raven start
raven start --daemon
ravenflow
raven doctor

raven doctor names the adapters that have credentials and the ones that would stay silent, so a misconfigured channel is visible before the first message. Configuration lives in .env; .env.example documents every variable.
