Server surfaces

Surface Detail

stdio (agent toolset) ravencode-mcp --workspace /path/to/project
module entry points python -m raven.core.mcp / python -m ravencode.mcp
JSON-RPC over HTTP POST /mcp/rpc
plain tool list GET /mcp/tools
direct tool call POST /mcp/tools/{name}
events + liveness GET /mcp/events, GET /mcp/health
auth X-Raven-Key or Authorization: Bearer
path confinement --workspace, rejects outside paths and symlink escapes

Get Started

1

Install

git clone https://github.com/ssrjkk/raven
cd raven
pip install .

Python 3.11+ · installs the raven-mcp and ravencode-mcp commands

2

Configure your client

{
  "mcpServers": {
    "raven": {
      "command": "raven-mcp",
      "args": ["--workspace", "/path/to/project"]
    }
  }
}
3

Use the tools

Ask the assistant to read a file, run a command or search the web. It calls the MCP tool and Raven executes it inside the workspace you allowed.
