AI Gateway with MCP Protocol

Connect Claude Desktop, Qoder, opencode, Cursor to 66+ tools through unified MCP server. One protocol, any editor, full workspace access.

MCP 2025-03-26 66+ Tools Stdio + HTTP

Quick Start

Install & Run
pip install -e ".[dev]"
raven-mcp --workspace /path/to/project

Add to Claude Desktop config (claude_desktop_config.json):

{
  "mcpServers": {
    "raven": {
      "command": "raven-mcp",
      "args": ["--workspace", "D:\\your\\project"]
    }
  }
}

What You Get

File Operations

  • read — Read files with line numbers
  • write — Create/overwrite files
  • edit — Surgical string replacements
  • glob — Pattern-based file search

Shell & Code

  • bash — Execute commands (timeout support)
  • lint — Run linters (ruff, eslint)
  • test — Run test suites
  • format — Code formatters

Web & Search

  • web_search — Search the web
  • web_fetch — Fetch & parse URLs
  • browser — Full browser automation
  • screenshot — Capture pages

Integrations

  • github — Issues, PRs, code search
  • git — Commits, diffs, history
  • mcp — Connect other MCP servers
  • custom — Add your own tools

Real Example

Ask Claude to fix a bug using Raven tools:

User → Claude Desktop
Fix the authentication bug in src/auth.py
Claude uses Raven tools
1. read(path="src/auth.py")
2. bash("grep -n 'login' src/auth.py")
3. edit(path="src/auth.py", old="...", new="...")
4. bash("pytest tests/test_auth.py")
5. bash("git add src/auth.py && git commit -m 'fix: auth'")

Claude sees your code, runs tests, commits fixes — all through MCP.
