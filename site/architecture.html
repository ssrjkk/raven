Each tool carries its own JSON Schema, so tools/list returns the parameter names and types a client needs before it calls anything. The two stdio servers answer the same registry and differ only in the name they report at initialize: raven-mcp and ravencode.

Where the server answers
Surface Detail
stdio, Raven server raven-mcp --workspace /path/to/project
stdio, RavenCode server ravencode-mcp --workspace /path/to/project
module entry points python -m raven.core.mcp / python -m ravencode.mcp
JSON-RPC over HTTP POST /mcp/rpc
plain tool list GET /mcp/tools
direct tool call POST /mcp/tools/{name}
events and liveness GET /mcp/events, GET /mcp/health
auth X-Raven-Key or Authorization: Bearer
path confinement --workspace, rejects outside paths and symlink escapes

Both transports end in the same handler: a frame that arrives over stdio and one that arrives at POST /mcp/rpc are parsed, dispatched and confined by the same code. That is why the console can show one recording for both.
