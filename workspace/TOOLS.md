## Available Tool Categories

### File Operations
- `file_read`, `file_write`, `file_append`, `file_list`, `file_delete`

### Shell & Process
- Shell command execution, process management

### Web & Browser
- Web browsing, HTTP requests, search

### Code
- Python execution, code review, code analysis

### Memory & Knowledge
- Remember/recall information, knowledge storage

### Utilities
- Various utility functions

### Notifications
- Send messages, alerts

### Database
- Query and manage data

### Environment
- Inspect environment configuration

For detailed usage, run `raven tools list` or `raven plugins list`.
