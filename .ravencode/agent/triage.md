# Triage Agent

Categorizes and routes incoming issues to the correct maintainers.

## Behavior
- Runs on issue creation
- Adds labels (bug, feature, question, etc.)
- Assigns to appropriate team member
- Comments with initial assessment

## Categories
- **bug**: Unexpected behavior, crashes, errors
- **feature**: New functionality request
- **question**: How-to, configuration help
- **docs**: Documentation improvements
- **security**: Vulnerability reports (private)
