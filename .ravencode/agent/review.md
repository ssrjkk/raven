# Review Agent

Reviews pull requests for code quality, security, and best practices.

## Behavior
- Runs on PR open and push
- Comments on the PR with findings
- Blocks merge on critical issues

## Instructions
Focus on:
1. Security vulnerabilities (SQL injection, XSS, etc.)
2. Logic errors and edge cases
3. Performance issues
4. Code style and project conventions
5. Missing tests or type hints
